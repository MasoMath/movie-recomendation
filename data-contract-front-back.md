# Data Contract

## Front → Back

### TypeScript (sent by client)
```typescript
export interface ApiSearchCategory {
    items: number[];
    weight: number;
}

export interface ApiSearchPayload {
    movies: ApiSearchCategory;
    actors: ApiSearchCategory;
    directors: ApiSearchCategory;
    genres: ApiSearchCategory;
    production_companies: ApiSearchCategory;
}
```

### Python (validated by server with Pydantic)
```python
class Category(BaseModel):
    items: list[int]
    weight: float

class InputFormatted(BaseModel):
    movies: Category
    actors: Category
    directors: Category
    genres: Category
    production_companies: Category
```

#### Index semantics
Items are integer indices, not string names. The meaning of each index depends on the category:

| Category | Index into |
|---|---|
| `movies` | DataFrame row position in `MovieData.get_data()` |
| `actors` | `MovieData.get_actors()` array |
| `directors` | `MovieData.get_directors()` array |
| `genres` | `MovieData.get_genres()` array |
| `production_companies` | `MovieData.get_prod_companies()` array |

The frontend asset files (`valid_movies.json`, `valid_actors.json`, etc.) are generated by `json_dump.py` from the same `MovieData` instance, so their array positions match these indices exactly.

At least one category must have a non-empty `items` list.

## Back → Front

### Python (sent by server)
```python
@dataclass
class HydratedMovie:
    id: int            # TMDB movie ID
    score: float
    title: str
    genres: list[str]
    cast: list[str]
    release_date: str
    directors: list[str]
    production_companies: list[str]
    poster_url: str | None

@dataclass
class Payload:
    input_movies: list[HydratedMovie]
    recommended_movies: list[HydratedMovie]
```

```typescript

});
```

## ML interface — `aggregate_similarity`

This is the boundary between the server pipeline (`helpers.py`) and the ML implementation (`similarity.py`).

### What the server passes in

```python
aggregate_similarity(
    movie_input,        # InputFormatted — the validated request (see index semantics above)
    moviedata,          # MovieData instance — use to access columns and lookup arrays
    genre_matrix,       # np.ndarray | None — pre-loaded genre semantic similarity matrix
    keyword_matrix,     # np.ndarray | None — pre-loaded keyword semantic similarity matrix
)
```

`genre_matrix` and `keyword_matrix` are `None` if `similarity_matrices/` has not been generated yet (unzip `similarity_matrices.zip`).

### What the server expects back

```python
list[tuple[int, float]]
# (DataFrame row index, similarity score), ordered highest score first.
# Must NOT include any row indices from movie_input.movies.items.
```

The server converts row indices to TMDB IDs and builds `list[MovieIdAndScore]` before passing results to the hydration layer. The ML code does not need to know about TMDB IDs or `HydratedMovie`.
